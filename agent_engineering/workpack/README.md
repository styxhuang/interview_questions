# 题包工作区

候选人运行 `INITIAL_PROMPT.md` 后，应在本目录建立并持续维护以下记录：

| 文件 | 内容 |
| --- | --- |
| `PROJECT_MAP.md` | 入口、模块职责、数据流、状态流和外部依赖 |
| `BASELINE.md` | 环境、版本、命令、原始测试结果和不可复现项 |
| `ISSUE_LOG.md` | 问题证据、影响、优先级、处理决定和验证方式 |
| `EXPERIMENT_LOG.md` | 每次假设、改动、命令、结果和结论 |
| `DECISIONS.md` | 重要设计选择、备选方案和取舍 |
| `COMMANDS.md` | 从干净环境复现安装、测试、评测和服务启动的命令 |

这些文件不是形式化日报。内容要能回答“为什么这样改、证据是什么、怎样复现”。不得写入 AccessKey、token、密码或未脱敏的环境变量。
